# Agent Note: MCP 配置所有权与增量加载

Status: superseded — 管理插件不再持有自己的 MCP 配置；见 2026-10-19 与 2026-10-20 两条记录。

## Problem

自定义 server 映射并不等于 DSH 的可加载 MCP 连接。配置编辑器修改已有条目，不提供通用的配置树节点创建方法。把整个管理插件重挂载会影响其 RPC、Runtime Skill 和已创建连接。

## Decision

主页面提供 MCP Server 工具分组、托管 MCP 新增/重试和 Skill 管理。新增表单分别收集 stdio 和 HTTP 定义。DSH 原生 MCP 使用各自的 `@deepseek-ai/dsh-mcp-client` 条目，由 DSH 插件管理器维护；托管新增保存到当前管理插件条目的 `managedServers`，不使用统一的 `mcp.servers` 路径。`mcp.add` 仅允许 Profile 全局写入，并复用运行版本及接口闸门。Host 通过当前 Fiber 定位配置条目，在 `configEditor.edit` 回调中检查取消和同名冲突，保留其他字段。映射 Tool/RPC 拒绝修改管理插件自身条目。失败项显示限定诊断，`mcp.retry` 在全局写闸门内只处理本地失败项，不重连健康项；单项清理失败保留可重试记录，不阻断其他连接。

`managedServers` 是 Schemastery volatile 字段。Loader 更新引用并发送本 Fiber 的 `loader/volatile-update` 后，串行同步按原始定义比较连接：未变化项保留实例，变化项释放自身子 Fiber 后重建。官方桥接器启用 `failOnStartupError`，首次连接或工具同步失败由子 Fiber 报告，使该项进入可重试的失败阶段；成功启动后的断线与重连由官方桥接器管理，不提供给本插件可靠的连接状态。模块异步加载完成后重查当前定义；过期定义和卸载后的异步工作不能创建新连接。桥接器导入和本地启动有等待上限；启动超时立即请求释放，未完成的释放仍占用该名称，直到子 Fiber 释放后才允许同名重试。单项清理超时不阻塞其他项；底层 Cordis `apply` 若永不结束且不支持协作取消，父 Fiber 卸载仍可能无法完成。官方桥接器拥有传输、工具注册及重连机制；它可能在传输关闭未获确认时仅记录诊断并完成释放，因此子 Fiber 释放不证明旧进程已退出。本插件拥有配置与其创建的子实例。

配置保存环境变量引用，不保存解析后的环境或请求头值。标准目录返回白名单摘要，不返回命令、地址、参数或原值。HTTP 地址不支持内嵌凭据、查询参数和片段；需要认证时使用请求头环境变量引用。

运行时工具目录按配置 Server 分组只作为便于浏览的名称候选：仅当 `serverName` 唯一，且工具名 `mcp__<serverName>__` 前缀只匹配一个 Server 时归入该组。缺少或重复配置名，以及匹配多个 Server 前缀的工具，保留在独立的未关联折叠组。名称匹配不证明工具注册来源，也不表示连接在线。页面直接读取 Profile 全局范围，Agent 调用管理工具的发现操作使用其自身作用域。

Host 映射 Tool/RPC 的目录为每个有效 Server 定义返回不含明文的修订标识。已有 Server 的完整替换必须携带目录中的 `expectedRevision`，Host 在 `configEditor.edit` 回调中比较当前有效定义；定义变化或消失时拒绝保存并要求刷新目录。Runtime Skill 列表按当前有效定义去重，只对本插件拥有且仍为有效定义的 Skill 提供注销；并发注销同名 Skill 只允许一次 disposer 运行。

## Alternatives considered

- 拼接 Profile YAML 创建原生行：绕开官方配置事务，增加并发覆盖和错误配置的风险。
- 把 server 定义放在普通字段：配置变化会导致整个管理插件重挂载，影响已有连接与服务。
- 自己实现 MCP 传输和工具注册：重复官方桥接器的协议与生命周期维护。
- 按名称前缀直接归属任一 Server：配置名称重叠或重复时会误关联工具。
- 仅在浏览器确认替换时比较配置：确认到 `configEditor.edit` 落盘之间仍可发生并发更新。

## Acceptance criteria

stdio/HTTP 表单直接提交托管定义。页面初始化只发起兼容检查、MCP 发现/托管同步和 Skill 目录请求，不提供配置映射路径、配置条目或映射编辑控件，不发起 `mcp.catalog`。Host 的映射目录、revision 和写入安全契约由 Tool/RPC 回归独立覆盖。重复名称、缺少引用变量、未知版本、非全局 RPC 范围和排队期间取消均不产生保存。并发同名请求只有一个成功。添加其他 server 时已有实例不重连；恢复配置可加载声明；正常完成启动的所属实例在插件卸载时释放。异步等待期间失效的定义不会启动。MCP 页面支持按 Server 和 MCP 命名候选工具搜索，并单独折叠关联不确定的配置条目和工具。

## Consequences

保存成功与连接成功是不同事实；返回 `saved` 和未知连接状态，不承诺远端可用。隔离桥接样本和真实 volatile 更新回归不代替目标桌面端的官方桥接器、实际命令与 HTTP 传输验收。新增配置不会自动安装 server 程序；初次安装插件与新增连接的生命周期分别处理。
