# Agent Note: DSH 升级兼容性与写入许可

Status: implemented — 目录读取与写操作分别判断兼容性。

## Problem

安装约束和方法存在性都不能证明运行时行为兼容。升级后仍允许写配置或注册 Runtime Skill，会把未经验证的接口行为带入持久化与生命周期操作。

## Decision

运行版本来自 DSH 公开包清单，读取失败不推测版本。精确的隔离回归基线由兼容模块维护；未知或未验证版本保持只读。基线匹配后仍检查每项操作的方法依赖。页面初始状态、检查错误和协议不匹配均禁用写操作；Host 在每次写入时独立检查，取消后不授权。兼容响应绑定会话，迟到响应不能授权其他视图。

目录和正文读取允许继续尝试，其失败独立显示。插件清理自身注册不受手动操作闸门阻碍。基础依赖使插件无法启动时，由 Loader 诊断，兼容页面不能替代启动保障。没有强制开启写入的配置开关。

## Alternatives considered

- 仅依赖 peer 范围：范围不能证明调用语义或配置生命周期保持一致。
- 仅检查方法存在：同名方法可能改变输入、返回值或持久化语义，不能作为写入授权依据。
- 所有功能在未知版本上一律关闭：会丢失可用的只读诊断入口，无法帮助定位升级问题。
- 复制或修改官方内部实现：增加维护面，并使插件与官方升级耦合；使用公开服务接口。

## Acceptance criteria

已测版本的现有回归保持通过。未来、未知版本及缺失关键方法时，RPC 和 Tool 写入都在产生修改前被拒绝；读取仍可返回结果。页面不能用失败、格式错误或迟到的兼容响应启用写入。取消授权检查后不发生写操作。安装包包含兼容模块和版本清单。

## Consequences

隔离回归名单不是完整运行环境认证。扩展名单需另做目标 DSH 的真实安装、页面和配置操作验收。隔离测试报告区分合成版本样本与真实运行环境；安装和目标运行时验收独立记录。
